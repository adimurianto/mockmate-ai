# MockMate AI 🎤

AI interview simulator built with Next.js + Groq.

---

## 🚀 About

MockMate AI helps you practice job interviews using AI.
It generates questions, example answers, feedback, and final review based on your CV and target role.

---

## ✨ Features

* AI-generated interview questions
* Example answers based on CV
* Speech synthesis for questions and answers
* AI feedback on your answers
* Final interview review (English + Indonesian)

---

## 🧠 Tech Stack

* Next.js
* Tailwind CSS
* Groq AI API
* TypeScript

---

## ⚙️ Setup

```bash
git clone https://github.com/yourusername/mockmate-ai.git
cd mockmate-ai
npm install
```

Create `.env`:

```
GROQ_API_KEY=your_api_key
```

Run project:

```bash
npm run dev
```

---

## 📌 Usage

1. Paste your CV
2. Enter target role
3. Generate interview
4. Practice answers with AI
